# PoC StrongBox & Citadeld

Repositorio de pruebas de concepto enfocado en la auditoría del componente de seguridad `citadeld` (Titan M3 / StrongBox) y la gestión de transacciones del bus SPI.

## Componentes
- Simulación de contención de bloqueos (Mutex / Binder death).
- Análisis de saturación en transacciones criptográficas.
